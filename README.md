# Traffic Sign Object Classification Dataset

Dataset ini dibuat untuk tugas **Object Classification** dengan objek berupa rambu lalu lintas yang ditemukan di lingkungan sekitar.

## Dataset Description

Dataset terdiri dari 4 kategori rambu lalu lintas:

- **Bus Stop**
- **U-Turn**
- **Speed Limit**
- **Roundabout**

Setiap kategori terdiri dari **15 citra**, sehingga total terdapat **60 citra**.

Seluruh citra dikumpulkan secara langsung menggunakan kamera pribadi.
